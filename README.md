# 🎬 React CinemaAddict

A movie discovery web app built with **React**, **Tailwind**, and the **TMDB API**. CinemaAddict lets you explore movies, search for titles, view detailed information, watch trailers, browse images, and discover similar movies. More features soon :D

🔗 [**View Live Demo on Vercel**](https://cinema-addict.vercel.app/)

## ✨ Features

* **Movie Discovery:** Browse sections for trending, popular, now playing, upcoming, and highly-rated movies.

* **Movie Search:** Search for movies using the TMDB database.
* **Movie Details:** View information including ratings, release date, runtime, genres, overview, cast, and crew.
* **Trailers:** Watch available movie trailers directly from the movie details page.
* **Image Gallery:** Browse backdrops and images related to a movie.
* **Recommendations:** Discover similar movies based on the movie you're currently viewing.
* **Responsive Design:** Clean and responsive interface built with Tailwind CSS.
* **Reusable Components:** Movie cards, rows, search components, buttons, and other UI elements are built as reusable React components.

## 🛠️ Tech Stack

* **Framework:** React (Vite)
* **Styling:** Tailwind CSS
* **Routing:** React Router
* **API:** TMDB API
* **Icons:** Lucide React
